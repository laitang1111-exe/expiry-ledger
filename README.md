# 保质期管理器（expiry-ledger）

给门店理货员用的离线保质期台账：扫条码入库、拍日期 OCR、按 7/10/20/30 天分段看板、已处理进回收站、行内编辑、自动备份。

- 纯本地 SQLite，不联网、不要账号
- Kotlin + Jetpack Compose，minSdk 26 / targetSdk 36
- 只用一个 Activity + Compose 状态机，SCREENS：首页 / 录入 / 搜索 / 回收站 / 设置

## 下载

所有安装包都在 **[Releases](../../releases)**（1.0 ~ 2.3，每个版本一个 APK，正式签名）。

最新版：**expiry-ledger-2.3-release.apk**

## 签名

全部版本使用同一把正式签名证书（自签名，非 debug）：

```
CN=保质期管理器, O=转生成为FX杠杆糕手, C=CN
RSA 2048 / SHA256withRSA
SHA-256 C8:A6:AF:A8:3F:07:9D:DD:F2:A7:EF:1B:B4:B2:68:2A:37:69:C0:C5:CD:ED:FE:52:83:8E:99:99:89:9F:36:34
有效期至 2300-09-04，签名方案 v2 + v3
```

注意：与早期 debug 签名的包不兼容，覆盖安装会失败，需先卸载旧版（先导出 JSON 备份数据）。

## 功能

| 功能 | 说明 |
|---|---|
| 扫码入库 | 首页右下角 + 直接进相机，扫到条码填进草稿；同条码自动带出名称和上次保质期 |
| 拍日期 | 摄像头中文 OCR 读生产日期，只接受早于今天的日期，否则丢弃并提示 |
| 拍名称 | 包装上最大的文字块做候选，按字号排序给 5 个，可点选或「重试」 |
| 分段看板 | 顶部 7 / 10 / 20 / 30 天四张可点卡片（互斥分段），点进去看该段明细 |
| 正常区 | 首页只列 30 天以上的批次，按到期日升序 |
| 剩余天数 | 「剩余 45 天」下一行显示「约等于 1 个半月」 |
| 行内编辑 | 点任意一行改名称 / 生产日期 / 保质期，改名会同步到同条码所有批次 |
| 已处理 | 二次确认后进回收站，可恢复或彻底删除（删除也有确认） |
| 防重复 | 同条码 + 同生产日期 + 同保质期视为同一批，拒绝重复添加 |
| 搜索 | 按条码 / 名称 / 生产或到期日期搜；支持扫码直接填进搜索框 |
| 识别音效 | 扫码、拍日期、拍名称识别成功时播「滴」声 |
| 导出/导入 | 设置页 JSON 导出与合并式导入（同三元组跳过） |
| 自动备份 | 每次保存（新增/编辑/已处理/恢复/删除/导入）自动快照到 `/sdcard/赏味期/20261120121354 - 存档.json` |

## 数据格式

导出/备份文件（也可从设置页导出）：

```json
{
  "app": "expiry_ledger",
  "version": 1,
  "exportedAt": "2026-11-20T00:12:34",
  "count": 1,
  "batches": [
    {
      "barcode": "6925303762889",
      "name": "统一老坛酸菜",
      "productionDate": "2026-08-04",

      "shelfLifeUnit": "月",
      "expiryDate": "2027-08-04",
      "deletedAt": null,
      "createdAt": 1795000000000
    }
  ]
}
```

## 构建

```bash
# 环境：JDK 17+、Android SDK 36、Gradle 9.x
gradle assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

`local.properties` 里的 `sdk.dir` 用正斜杠，例如 `sdk.dir=F:/sdk`（反斜杠会被转义，Gradle 会报 Invalid file path）。

## 目录

```
app/src/main/java/com/lidesheng/expiryledger/
    MainActivity.kt   骨架：Screen 状态机 + 所有保存动作后的自动备份
    Ui.kt             首页 / 录入 / 搜索 / 回收站 / 设置 全部 Compose 界面
    CameraScreen.kt   相机（条码 / 文字 OCR / 名称候选）+ 识别音效
    Db.kt             SQLiteOpenHelper + 仓库层（增删改查、搜索、导入）
    Model.kt          数据类、到期日计算、阶段阈值、OCR 文本解析
    Backup.kt         JSON 导出/导入、自动备份
```
